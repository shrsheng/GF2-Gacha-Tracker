# GF2 Gacha Tracker

《少女前線 2：追放》本地抽卡紀錄與統計工具。

GF2 Gacha Tracker（GF2GT）將一般招募、新裝採購與神秘箱紀錄集中整理，提供帳號摘要、卡池分析、菁英出貨歷史、人形／專武養成成本及特殊紀錄。所有個人資料皆保存在使用者電腦。

> 本專案為玩家製作的非官方工具，與 SUNBORN／散爆網路及 Haoplay 無關。

## 功能總覽

| 頁面 | 主要用途 |
| --- | --- |
| 統計總覽 | 快速比較帳號整體與五種一般招募池表現 |
| 招募分析 | 依卡池查看出貨事件、時間軸、進階圖表與卡池履歷 |
| 人形與軍備 | 檢視人形、專武、椎體、調校及取得成本 |
| 特殊紀錄 | 查看歐非紀錄、連勝／連敗、6＋1、6＋6 與排行榜 |
| 資料中心 | 同步設定、匯入／匯出、額外取得與原始抽卡紀錄 |

### 統計總覽

- 帳號摘要：累計抽數、菁英總數、平均成本與 UP 命中率。
- 卡池順序：定向採購、軍備提升、常規採購、自選人形、自選武器。
- 桌面視窗一次顯示三張卡片，可使用箭頭、觸控板或 `Shift + 滾輪` 水平切換。
- 顯示模式：出貨效率、UP 表現、歐非紀錄、自訂顯示。
- 自訂顯示可從所有指標中依勾選順序排列，至少保留一項且不限制三項。
- 顯示偏好與滑動位置按帳號隔離，不會混用不同帳號資料。

### 招募分析

招募分析使用兩層卡池導覽：

| 招募類型 | 卡池 |
| --- | --- |
| 限定招募 | 定向採購、軍備提升 |
| 常規招募 | 常規採購、新手採購 |
| 自選招募 | 自選人形、自選武器 |
| 特殊招募 | 新裝採購、神秘箱 |

一般招募池提供：

- 累計抽數、菁英機率、平均菁英抽數、平均 UP 抽數及 UP 命中率。
- Recent Elite 頭像網格，支援全部／UP／歪篩選。
- 視覺化詳細時間軸：命中使用綠色、歪出使用紅色、無 UP 機制使用黃色。
- 頭像與時間軸共用同一組已排序事件，不因切換檢視重新計算抽數。
- 進階分析預設收合，包含最歐、最非、最非含歪、招募結果組成及抽數分布。
- 菁英出貨分布上限為 80 抽；UP 取得成本以含歪的完整成本統計。
- 各期卡池履歷使用卡池名稱、投入抽數及開放時間，不直接顯示 `pool_id`。

常規／新手採購不會產生虛假的 UP 統計。新裝採購與神秘箱使用各自的專用統計，不套用一般菁英池公式。

### 人形與軍備

提供三種模式：

- **人形＋專武**：以人形為中心，整合本體、椎體、專武、調校及取得成本。
- **人形**：依人形彙總所有可識別卡池，不以單一 `pool_id` 拆卡。
- **武器**：依武器彙總所有可識別卡池，不以單一 `pool_id` 拆卡。

共用功能：

- 即時名稱搜尋。
- 近期取得、總抽數、平均 UP 成本、UP 命中率及名稱排序。
- 依取得狀態、卡池類型、抽歪紀錄、6＋1／6＋6 篩選。
- 卡片顯示 UP 機率、平均 UP 抽數與命中率。
- 角色立繪與完整武器圖片；缺圖時使用統一佔位畫面。
- 點擊卡片開啟右側 Drawer，內容統一為「統計總覽／出貨紀錄／卡池履歷」。
- 卡池履歷顯示卡池名稱、投入抽數與起訖日期，不向一般使用者顯示 `pool_id`。

### 額外取得

可在「資料中心 → 額外取得」登記透過禮包、周年自選或活動獲得的菁英人形與武器。

- 名稱清單會依人形／武器類型過濾。
- 僅允許菁英人形與菁英武器，不顯示禮盒、衣裝或其他道具。
- 額外取得會影響持有數量、椎體或調校顯示。
- 不會加入抽卡總數、菁英機率、平均菁英抽數、平均 UP 成本或 UP 命中率。
- 每個帳號分開保存，並包含在該帳號的 JSON 備份中。

### 特殊招募

#### 新裝採購

- 限定衣裝與稀有衣裝取得順序。
- 衣裝部件、武器塗裝與部件、精雕奇異造物、位鍵及火控演化禮盒統計。
- 支援克萊妲「衣裝．濯浪焦點」卡池及其美術。

#### 神秘箱

- 限定／稀有獎品統計。
- 限定人形按 90 碎片換算，稀有武器按 18 碎片換算。
- 每 30 碎片換算 1 抽，顯示總抽數與剩餘碎片。

### 多帳號

- 以「伺服器＋UID」識別帳號，可另外設定顯示名稱。
- 每個帳號獨立保存抽卡紀錄、額外取得及同步設定。
- 切換帳號會清除上一個帳號的畫面狀態並重新載入統計。
- 匯入、匯出、同步、補登及清除只會影響目前帳號。
- 舊版單帳號資料首次啟動時會自動搬入多帳號資料庫，原始檔案不會被刪除。

## 下載與安裝

請前往 [GitHub Releases](https://github.com/shrsheng/GF2-Gacha-Tracker/releases) 下載最新的 Windows 安裝程式。

1. 下載 `GF2 Gacha Tracker Setup x.x.x.exe`。
2. 執行安裝程式並啟動 GF2GT。
3. 進入「同步設定」。
4. 填入自己的 `gachaUrl` 與 `Authorization`。
5. 按下更新資料，完成後即可查看統計。

> `Authorization` 屬於個人登入資訊。請勿公開、截圖分享或提交到 GitHub Issue。

## 資料保存與安全

- 抽卡紀錄、帳號資料與同步設定保存在 Electron 的本機 `userData/data` 目錄。
- 專案原始碼、安裝程式及線上資料更新不包含使用者帳號資料。
- 更新程式通常不會刪除資料，但大量補登、換電腦或跨版本更新前仍建議匯出備份。
- 移除帳號不會自動建立備份，請先切換至該帳號並匯出 JSON。

備份位置：

```text
匯入／匯出 → 匯出 JSON
```

## 匯入紀錄

### GF2GT 備份

匯出的 JSON 包含目前帳號的基本資料、抽卡紀錄及額外取得，可用於換電腦或復原資料。

### gfl2help

- 支援直接匯入 gfl2help JSON。
- 多伺服器資料會先要求選擇來源。
- 匯入前顯示可新增筆數與未知物件數量。
- 程式會先備份目前紀錄，再執行合併與去重。
- 本機獨有紀錄不會被刪除或覆蓋。
- 神秘箱與新裝採購稀有度以 GF2GT 物件表重新判定。

### 手動補登

官方 API 只能取得一定期間內的紀錄。若曾保存更早的出貨資料，可下載手動模板補進統計。

逐抽紀錄範例：

```json
[
  {
    "time": "2025-01-01 12:00:00",
    "source": "定向採購",
    "type": "人形",
    "name": "黛煙",
    "rarity": "橙色"
  }
]
```

只有菁英出貨摘要時，可使用 `pullCount`：

```json
[
  {
    "time": "2025-01-01 12:00:00",
    "source": "定向採購",
    "type": "人形",
    "name": "黛煙",
    "rarity": "橙色",
    "pullCount": 80
  }
]
```

| 欄位 | 必填 | 說明 |
| --- | --- | --- |
| `time` | 是 | `YYYY-MM-DD HH:mm:ss` |
| `source` | 是 | 定向採購、軍備提升、常規採購、自選人形或自選武器 |
| `type` | 是 | 人形或武器 |
| `name` | 是 | 遊戲內名稱 |
| `rarity` | 是 | 橙色、紫色或藍色 |
| `pullCount` | 否 | 該次菁英出貨間隔，必須為正整數 |

手動資料不會覆蓋 API 紀錄。缺少必要欄位、格式錯誤或落在已同步日期範圍內的重複資料會被跳過。

## 統計口徑

- **菁英機率**：菁英出貨數 ÷ 有效抽數。
- **平均菁英抽數**：有效抽數 ÷ 菁英出貨數。
- **UP 命中率**：UP 次數 ÷（UP 次數＋抽歪次數）。
- **平均 UP 抽數**：已取得 UP 的完整累計成本 ÷ UP 次數，包含取得 UP 前的抽歪成本。
- **目前墊抽**：尚未取得下一個 UP 的抽數，不會提前加入平均 UP 抽數。
- 常規採購與新手採購沒有 UP 機制，因此不計算 UP 命中率與平均 UP 抽數。
- 介面切換、動畫、篩選及排序只改變顯示，不會重新寫入或刪除抽卡紀錄。

## 更新資料表與美術

「匯入／匯出 → 更新資料表與美術」可取得新物件表、卡池資料及圖片，不必重新安裝程式。

更新清單由 `data-update-manifest.json` 管理。程式會先下載並驗證所有檔案的 SHA-256，全部成功後才寫入使用者資料夾；下載中斷或驗證失敗不會覆蓋現有檔案。

目前可更新內容包含：

- `itemMap.json`
- `outfitPoolMap.json`
- `characterArtMap.json`
- `weaponArtMap.json`
- `signatureMap.json`
- 角色、武器及特殊招募圖片

## 開發與測試

需求：

- Node.js 20 或更新版本
- npm
- Windows 10／11（正式安裝包與實際使用環境）

安裝依賴並啟動：

```bash
npm ci
npm start
```

執行自動測試：

```bash
npm run test:overview
```

建立 Windows 安裝程式：

```bash
npm run dist
```

輸出檔案位於 `dist/`。Windows NSIS 安裝程式建議直接在 Windows 或已正確安裝 Wine 的建置環境產生。

## 注意事項

- 本工具只讀取抽卡紀錄 API，不會修改遊戲帳號或遊戲資料。
- 請勿公開 `Authorization`、同步網址、完整設定截圖或未遮蔽的備份檔。
- 官方 API 可查詢的歷史期間可能隨遊戲版本調整。
- 圖片或卡池名稱缺失時，可先使用內建資料更新功能。
- 額外取得只用於補充持有狀態，不應拿來模擬抽卡紀錄。
