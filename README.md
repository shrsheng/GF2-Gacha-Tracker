# GF2 Gacha Tracker

《少女前線 2：追放》本地抽卡紀錄與統計工具。

將定向採購、軍備提升、常規採購與自選卡池的紀錄集中整理，提供卡池總覽、橙色出貨時間軸、個別 UP 成本、人形與專武進度等分析。所有個人抽卡資料皆保存在本機。

> 本專案為玩家製作的非官方工具，與 SUNBORN／散爆網路無關。

## 主要功能

### 統計總覽

- 定向採購、軍備提升與常規採購統計
- 總抽數、橙色數量、平均出橙抽數與 UP 率
- 最歐、最非及歪角紀錄
- 自選人形、自選武器卡池支援

### 特殊紀錄

- 最大連續不歪與最大連續抽歪
- 最歐十連紀錄
- 最歐／最非 6＋1
- 最歐／最非 6＋6

### 招募歷史

- 依卡池切換橙色出貨時間軸
- 顯示每次出貨使用抽數、角色／武器名稱及時間
- 顯示目前墊抽與歷史出貨效率

### UP 抽卡分析

- 同角色復刻卡池合併統計
- 自選池紀錄與定向／軍備池進度整合
- 個別人形與武器的出橙機率、平均抽數及 UP 率
- 記錄取得本體、椎體、專武與調校等級所使用的抽數
- 人形＋專武整合進度與目前累計總抽數
- 依 `signatureMap.json` 自動配對人形與專武

### 資料管理

- 從遊戲抽卡紀錄 API 同步
- JSON 備份匯入／匯出
- 舊資料相容與紀錄去重
- 手動補登早期歷史資料
- 線上更新 `itemMap.json`
- 檢查程式新版本

## 下載與安裝

請前往 [Releases](https://github.com/shrsheng/GF2-Gacha-Tracker/releases) 下載最新的 Windows 安裝程式。

1. 下載 `GF2 Gacha Tracker Setup x.x.x.exe`。
2. 執行安裝程式。
3. 開啟工具並進入「同步設定」。
4. 填入自己的 `gachaUrl` 與 `Authorization` 後更新資料。

> `Authorization` 屬於個人登入資訊，請勿截圖、公開或提供給其他人。

## 資料保存與備份

抽卡紀錄與同步設定皆保存在使用者電腦，不會提交到此 GitHub 儲存庫。更新程式通常不會刪除既有資料，但仍建議在大量補登、換電腦或更新版本前使用：

```text
匯入／匯出 → 匯出 JSON
```

## 手動補登歷史紀錄

官方 API 只能取得一定期間內的抽卡紀錄。如果曾自行保存更早的出貨資料，可以利用手動模板補進統計。

### 操作方式

1. 選擇「匯入／匯出」。
2. 點擊「下載手動模板」。
3. 使用文字編輯器填寫歷史資料並保存為 JSON。
4. 點擊「匯入手動紀錄」並選擇檔案。
5. 確認新增、重複與跳過筆數。

### 完整逐抽紀錄

```json
[
  {
    "time": "2025-01-01 12:00:00",
    "source": "定向採購",
    "type": "人形",
    "name": "黛煙",
    "rarity": "橙色"
  },
  {
    "time": "2025-01-01 12:00:01",
    "source": "定向採購",
    "type": "武器",
    "name": "舊式武器名稱",
    "rarity": "紫色"
  }
]
```

### 只補登橙色出貨

如果沒有保存逐抽紀錄，可以使用 `pullCount` 填寫該次橙色出貨所花費的抽數：

```json
[
  {
    "time": "2025-01-01 12:00:00",
    "source": "定向採購",
    "type": "人形",
    "name": "黛煙",
    "rarity": "橙色",
    "pullCount": 80
  }
]
```

這筆資料代表黛煙於該輪第 80 抽取得。

若先歪出常駐角色，再取得 UP 角色，請依實際出貨順序填寫：

```json
[
  {
    "time": "2025-01-01 12:00:00",
    "source": "定向採購",
    "type": "人形",
    "name": "維普蕾",
    "rarity": "橙色",
    "pullCount": 65
  },
  {
    "time": "2025-01-02 12:00:00",
    "source": "定向採購",
    "type": "人形",
    "name": "M200",
    "rarity": "橙色",
    "pullCount": 70
  }
]
```

程式會將兩位 UP 角色之間的非 UP 橙色視為歪角。上述範例會統計為 M200 共花費 135 抽，並在過程中於 65 抽歪出維普蕾。

### 欄位說明

| 欄位 | 必填 | 說明 |
| --- | --- | --- |
| `time` | 是 | 抽卡時間，格式為 `YYYY-MM-DD HH:mm:ss` |
| `source` | 是 | 定向採購、軍備提升、常規採購、自選人形或自選武器 |
| `type` | 是 | 人形或武器 |
| `name` | 是 | 遊戲內顯示的人形或武器名稱 |
| `rarity` | 是 | 橙色、紫色或藍色 |
| `pullCount` | 否 | 該次橙色出貨所花費的抽數，必須為正整數 |

### 匯入規則

- API 同步紀錄優先於手動資料。
- 落在目前 API 已同步日期範圍內的手動資料會自動跳過。
- 手動匯入不會覆蓋或修改 API 紀錄。
- 缺少必要欄位或格式錯誤的資料會跳過。
- `pullCount` 補登資料會參與統計與招募歷史分析，但不會展開成大量虛構的逐抽紀錄。

## 已測試環境

- Windows 10／11
- Haoplay 亞服

其他伺服器理論上可使用，但尚未完整測試。

## 注意事項

- 本工具只會讀取抽卡紀錄 API，不會修改遊戲帳號或遊戲資料。
- 請勿公開自己的 `Authorization`、同步網址或完整設定截圖。
- 官方 API 可查詢的歷史期間可能隨版本調整。
- 遊戲更新後若出現未知人形或武器，可先使用程式內的資料表更新功能。
