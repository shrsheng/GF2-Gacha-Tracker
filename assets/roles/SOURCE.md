# Character art source

Character illustrations, desktop character displays, and shared role-page backgrounds in this directory were downloaded from:

- https://gf2.pde.tw/roleinfo/?role=55
- Asset CDN: https://res.17996cdn.net/

Downloaded and optimized on 2026-08-30 for offline use in this unofficial fan-made statistics tool.

The files were resized and converted to WebP to reduce the packaged application size. `tools/download-role-assets.js` can rebuild the collection and `characterArtMap.json` when the source site adds characters.
