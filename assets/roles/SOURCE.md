# Character art source

Character illustrations, desktop character displays, and shared role-page backgrounds in this directory were downloaded from:

- https://gf2.pde.tw/roleinfo/?role=55
- Asset CDN: https://res.17996cdn.net/
- https://gf2.sunborngame.com/main/allRoles
- https://gf2.sunborngame.com/main/roleInfo
- Mainland China official CDN: https://gf2-cn.cdn.sunborngame.com/

Downloaded and optimized on 2026-08-30 for offline use in this unofficial fan-made statistics tool.

The original international illustrations and displays were resized and converted to WebP. The `heads/` directory contains the 69 standalone transparent head PNGs used by official role-detail switchers, retained at their original size. `characterArtMap.json` selects the dedicated head image first and falls back to the local display or illustration.
